统一基类

GeometryData 说明父类和子类的关系

`GeometryData` 是父类，点、线、圆、圆弧、向量和平面是子类。父类规定统一能力：能解释自己的数据结构，能转换为 PyVista 数据，能调用渲染引擎。

@dataclass(kw_only=True)
class GeometryData(ABC):
    name: str = ""

    @abstractmethod
    def to_pyvista(self) -> pv.DataSet:
        ...

    def render(self, engine, color="steelblue") -> None:
        engine.add_mesh(self.to_pyvista(), color=color)

    def data_structure(self) -> dict[str, object]:
        ...
面向对象编程

类的继承：父类与子类

继承（Inheritance）是面向对象的核心。子类自动获取父类的属性和方法，同时可以添加特有属性或重写父类行为，避免重复造轮子。

继承关系演示：Student 和 Teacher 类继承自 Person 父类。
class Person:
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age
    def introduce(self) -> str:
        return f"我是 {self.name}，今年 {self.age} 岁。"

class Student(Person):
    def __init__(self, name: str, age: int, student_id: str):
        super().__init__(name, age) # 继承并初始化父类属性
        self.student_id = student_id
    def introduce(self) -> str:
        base = super().introduce()  # 扩展父类自我介绍
        return base + f" 学号: {self.student_id}"
行为动态扩展

面向切面：Python 装饰器

装饰器（Decorator）是包装函数或方法的工具。在不修改被装饰对象源码的情况下，动态地为它添加诸如“日志拦截”、“性能计时”等横切逻辑。

语法糖：通过 @decorator 简写，实现零侵入的代码监控与性能统计。
def time_spent(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        res = func(*args, **kwargs) # 执行原方法
        elapsed = time.perf_counter() - start
        print(f"执行耗时: {elapsed:.4f} 秒")
        return res
    return wrapper

class Student(Person):
    @time_spent # 使用计时装饰器监控行为耗时
    def study(self, course_name):
        time.sleep(0.5)
特殊方法 / 运算符重载

认识 Python 的“魔法方法”

以双下划线开头的特殊方法（又称 Dunder Methods）是 Python 的特殊接口，它们允许自定义类型与 Python 的内置语法、运算符（如 +、-、print）无缝衔接。

魔力所在：重载运算符能让三维几何对象的数学运算写起来和手写公式一样直观！
# 1. 构造与表达
__init__(self, ...) : 实例化时的构造函数，用于初始化属性
__repr__(self)      : 开发者友好的对象描述（在控制台/调试时显示）
__str__(self)       : 面向用户的可读描述（print 打印时自动触发）

# 2. 运算符重载（几何对象极其常用）
__sub__(self, other): 重载减号 (-) -> Point3D - Point3D 得到 Vector3D
__add__(self, other): 重载加号 (+) -> Point3D + Vector3D 得到 Point3D
__mul__(self, val)  : 重载乘号 (*) -> 向量与标量缩放

# 3. 比较与通用方法
__eq__(self, other) : 重载 == 号 -> 判定两点是否重合（空间冲突检测）
__len__(self)       : 支持 len() 函数 -> 如返回折线采样的段数
点与向量

点表示位置，向量表示方向和长度

两个点相减得到向量。向量可以计算长度、归一化和缩放，是坐标变换、构件方向和法向量的基础。

start = Point3D(0, 0, 0)
end = Point3D(3, 4, 0)

vector = end - start
print(vector)          # Vector3D(3, 4, 0)
print(vector.length()) # 5.0
print(start.data_structure())
坐标系

坐标系是局部几何的参照

工程中常有全局坐标系和构件局部坐标系。坐标系由原点和三个轴向量组成，可渲染为三条彩色轴线。

local = CoordinateSystem3D(
    origin=Point3D(6000, 3000, 0),
    axis_length=1500,
    name="Column local system",
)

for axis in local.axes():
    print(axis.name, axis.start, axis.end)
线与面

线表达轴线，面表达边界或剖切面

梁轴线、管线中心线可以用 `Line3D` 表达；楼板面、墙面、剖切面可以用 `Plane3D` 表达。

beam_axis = Line3D(
    Point3D(0, 0, 3300),
    Point3D(6000, 0, 3300),
)
floor = Plane3D(
    center=Point3D(3000, 0, 0),
    normal=Vector3D(0, 0, 1),
    size=7000,
)
圆和圆弧

曲线可以通过采样点近似渲染

渲染引擎更容易显示点列和折线，所以圆和圆弧先采样为一组点，再转换为 PolyData 曲线。

pipe = Circle3D(Point3D(0, 0, 0), radius=500)
road = Arc3D(
    Point3D(0, 0, 0),
    radius=3000,
    start_angle=0,
    end_angle=math.pi / 2,
)

print(road.sample_points(count=5))
与引擎交互

对象自己知道如何进入视口

每个几何对象都提供 `render(engine)`。调用时不需要关心内部是点、线、面还是曲线。

engine = RenderEngine()
objects = [
    CoordinateSystem3D(axis_length=1500),
    Point3D(6000, 3000, 0, name="Column center"),
    Line3D(Point3D(0, 0, 3300), Point3D(6000, 0, 3300)),
]

for item in objects:
    item.render(engine)

engine.show()
