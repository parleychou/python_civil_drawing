01.01 课程综述

土木人为什么要学 Python？

这不是一门单纯讲语法的课，而是从图纸、坐标、构件和模型出发，用 Python 建立工程问题的数字化表达能力。

工程制图 几何建模 参数化 CAD/BIM 自动化
从痛点开始

传统工程工作里，重复劳动太多

画图、改图、统计、检查、导出报告，这些工作常常依赖人工经验和软件菜单。Python 的价值，是把这些动作变成可复用、可检查、可批量执行的流程。

1重复画图：轴网、梁柱、洞口
2重复统计：长度、面积、体积
3重复检查：交点、净距、碰撞
4重复输出：DXF、模型、报告
Python 的第一层价值

门槛低，但上限不低

容易开始

语法接近自然语言，适合从工程计算、小脚本和数据处理切入。

胶水语言

可以连接 Excel、CAD、BIM、数据库、Web 服务和各种专业库。

资源丰富

开源教程、示例代码和社区资料多，适合持续自学和工程落地。

低门槛的意义不是“简单”，而是让土木专业学生更快进入工程问题本身。
生态丰富

Python 像一个工程工具箱

PyPI 和 Conda 让我们可以直接调用成熟工具，把精力放在“如何表达工程对象”和“如何组织计算流程”上。

计算与数据

  • NumPy：向量、矩阵、坐标变换
  • Pandas：工程表格与统计
  • OpenPyXL：Excel 输入输出

图形与建模

  • Matplotlib：二维图表
  • PyVista：三维渲染

本课程的切入点

从图形学升级工程制图

土木工程天然依赖几何表达。CAD/BIM 软件背后，仍然是点、线、面、体、坐标系、变换、相交、布尔运算和碰撞检测。

学会用代码表达几何，才能真正理解软件菜单背后的原理。
点：柱心 / 节点
线：梁轴线 / 管线
坐标系：工程空间
核心主线

把工程对象变成可计算对象

参工程参数：跨度、截面、标高、管径
点坐标与向量：节点、方向、局部坐标系
形曲线、曲面、实体：梁、柱、墙、板、管线
算变换、相交、布尔、碰撞检测
出渲染、DXF、模型文件、报告
这门课不怎么讲

不从语法清单开始

变量、函数、循环、类、模块都会讲，但它们会放在具体工程问题中出现。先让学生知道“为什么需要它”，再学习“如何写出来”。

讲法转换

  • 不是：先学所有 Python 语法
  • 而是：先计算梁自重，再抽象成函数
  • 不是：先讲矩阵定义
  • 而是：先放置柱网，再理解 4×4 变换
  • 不是：先讲库 API
  • 而是：先生成图纸，再拆解 DXF 对象

自动生成

自动检查

检查相交、开洞、净距和碰撞，输出可追溯的结果。

自动输出

生成渲染截图、DXF 图纸、模型文件和 Excel 报告。

一次最小闭环

从参数到图纸，只看一个简单例子

这段代码不是为了展示语法，而是展示思维：工程对象可以被参数化、函数化，并最终进入自动化流程。

def beam_weight(length_m, width_m, height_m, density=25.0):
    volume = length_m * width_m * height_m
    return volume * density

weight = beam_weight(6.0, 0.3, 0.6)
print(weight)  # 27.0 kN
