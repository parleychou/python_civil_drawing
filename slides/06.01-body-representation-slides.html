从“点线面”到“体”的本质飞跃

前一章我们建立了基础图元（Point、Line、Plane）。但当工程进入真实结构世界时，单纯的坐标与向量已无法支撑实体建模：

  • “体”究竟是什么？ 计算机中没有任何原生的“实心原子”，体必须通过边界或离散单元在数学上严格定义。
  • 多元场景的诉求冲突：大跨屋盖需要无限光滑的连续曲面；BIM施工图需要严密封闭的实体来支持打洞开槽；有限元受力与GPU渲染则必须切碎成面片。
没有一种单一数据结构能统领全部场景。必须根据精度、拓扑、运算与显示需求采用不同的几何表达范式！
1D 线框模型 (Wireframe)：仅有棱边，内部中空无面，产生多义性二义性
2D 曲面模型 (Surface)：具备空间形状与连续切向，但无封闭厚度与体腔
3D 拓扑实体 (B-Rep)：利用封闭边界环与面严格划分实体内部与外部
离散 网格模型 (Mesh)：抛弃复杂指针，以极简数组拼合逼近，专供GPU高速光栅化与FEA

基于 GeometryData 的面向对象设计

为了深入底层的数学映射与拓扑指针，本讲不调用黑盒 CAD 库，纯手写 Python 数据类并继承自第 05 章的 GeometryData 基类：

  • 抽象接口契约：强制实现 to_pyvista() 方法，实现多态转换。
  • 解耦内核与表现：几何对象只负责数学表达和拓扑存储，统一交由 RenderEngine 调用 PyVista 进行窗口渲染。

from core.geometry_data import GeometryData, Point3D
import pyvista as pv

class ParametricSurfaceData(GeometryData, ABC):

    u_range: tuple[float, float]
    v_range: tuple[float, float]
    u_res: int
    v_res: int

    @abstractmethod
    def evaluate(self, u: float, v: float) -> Point3D:
        """数学解析映射：S(u, v) -> Point3D"""
        pass

    def to_pyvista(self) -> pv.StructuredGrid: ...

class BrepData(GeometryData):
    """B-Rep 边界表示：顶点坐标 + 棱边索引 + 面环拓扑"""
    vertices: tuple[Point3D, ...]
    edges: tuple[tuple[int, int], ...]
    faces: tuple[tuple[int, ...], ...]
    def to_pyvista(self) -> pv.PolyData: ...

class MeshData(GeometryData):
    """Mesh 网格：顶点缓冲 + 面片索引列表"""
    vertices: tuple[Point3D, ...]
    faces: tuple[tuple[int, ...], ...]
    def to_pyvista(self) -> pv.PolyData: ...
范式一：参数曲面

原理：双参数连续映射与微分几何

参数曲面通过二维参数域 (u, v) 建立到三维空间的连续向量函数：

S(u, v) = ( x(u, v),   y(u, v),   z(u, v) )
  • 无限数学分辨率：不存在多边形棱角锯齿，在理论上可在任意微小步长下进行解析求值。
  • 严密微分几何性质： 偏导切向量 Tu = ∂S/∂u,   Tv = ∂S/∂v 决定切平面；
    单位法向量为叉积规范化：n = (Tu × Tv) / ‖Tu × Tv‖。
  • 采样重构：在参数空间网格采样 M × N 点阵，送入 StructuredGrid 还原光滑表面。

双曲抛物面 (马鞍面) 参数化表达

土木大跨空间薄壳与索网屋盖经典参数解析方程：

S(u, v) = u i + v j + c · [ (u / a)² − (v / b)² ] k
⎧ x(u, v) = u
⎨ y(u, v) = v
⎩ z(u, v) = c · [ (u / a)² − (v / b)² ]
  • 参数域：(u, v) ∈ [−umax, umax] × [−vmax, vmax]，投射为底面平面网格。
  • 曲率基准 (a, b)：控制 X / Y 轴向抛物线开合跨度（代码默认 1500 mm）。
  • 矢高系数 (c)：控制中心鞍点到边界角点的高差幅度（代码默认 600 mm）。
  • 直纹曲面性质 (Ruled Surface)：曲面上每一点均交汇两条空间直母线，是索网结构能够使用平直预应力拉索张拉成型的几何本质。
  • 微分曲率特性：负高斯曲率（K < 0，沿正交轴一凹一凸），天然具备抗风振自平衡刚度。
* 笛卡尔二次曲面隐式形式：z / c = x² / a² − y² / b²

参数域 (u, v) 采样与空间点阵求值

参数曲面的第一步是离散采样：在二维参数空间 (u, v) ∈ [−L, L] × [−L, L] 划分规则步长，输入解析函数评估出三维点阵：

  • 解析求值：每个网格节点 (ui, vj) 代入 S(u, v) 独立算出 (x, y, z) 坐标。

Pi,j = evaluate(ui, vj) = Point3D(ui,   vj,   c · [ (ui/a)² − (vj/b)² ])

范式一：参数曲面

作用：大跨度空间结构、异形幕墙与自由找形

空间薄壳与索网屋盖

双曲抛物面（鞍形）是大型体育场、航站楼常用的结构造型。负高斯曲率使索网在双向张拉时获得天然的自平衡与抗风颤刚度，无需额外重型梁柱支撑。

连续建筑异形表皮

扎哈、极值形态建筑幕墙设计要求曲面保持 C1（切向连续）或 C2（曲率连续），消除光影反光折痕。参数曲面是计算机辅助曲面造型（CAS）的源头。

空间桥梁与箱梁放样

变截面连续梁桥底板曲线、斜拉桥空间主塔与螺旋匝道，依托中心脊线配合截面参数方程进行空间沿路径连续放样（Lofting / Sweeping）。

优势与局限：公式解析轻量（几百字节即可定义大型屋盖），解析法向完美；但只表达 2D 无厚度壳面，不具备实心内部体腔，无法直接执行 3D 实体布尔差集（开洞扣减）。
范式二：边界表示法

原理：欧拉公式与几何拓扑严格解耦

B-Rep (Boundary Representation) 的根本公理：“三维实心体由包围它的封闭二维边界表面所唯一确定”。

  • 欧拉-庞加莱公式：多面体顶点 V、边 E 与面 F 严格服从拓扑平衡： V − E + F = 2(1 − g)（简单体 V − E + F = 2）。
  • 几何 (Geometry) vs 拓扑 (Topology)：
    • 几何：点坐标 (x, y, z)、棱线方程、表面解析面（定义“在哪里、多大”）；
    • 拓扑：Vertex → Edge → Loop (Wire) → Face → Shell → Solid（定义“谁与谁相接”）。
  • 法向一致性：面外法向量严格背离实体内部朝外，赋予计算机判断“体内/体外”的绝对依据。

以六面体 (长方体 Box) 为例

长方体拥有标准的 B-Rep 拓扑元素结构：

• 8 个几何顶点 (Vertex)：三维角点坐标。
• 12 条拓扑棱边 (Edge)：连接角点的边界线。
• 6 个闭合表面 (Face)：各由 4 条边围合成环。
• 欧拉校验：8 - 12 + 6 = 2（严格守恒）。

范式二：边界表示法

作用：CAD/BIM 实体造型与高精度布尔运算

工业 CAD/BIM 建模内核基石

Revit、Tekla、AutoCAD、Rhino 及开源 OpenCASCADE (OCC)、Parasolid 底层均以 B-Rep 为唯一法定核心。IFC 工业基础类标准中绝大多数构件均为 B-Rep 描述。

精确布尔运算 (Boolean CSG)

柱与梁交汇剪切、梁贯通打螺栓孔、剪力墙开预留洞口。B-Rep 能精确求出相交交线并将面切割再拼合（交集 Intersect、并集 Union、差集 Cut），永不失真。

特征倒角与工程量精算

混凝土柱四角倒圆角 (Fillet)、钢结构边缘倒棱 (Chamfer)。因为完整记录了邻接面与公共边，可精确计算封闭体积、质量、净空与构件间物理碰撞 (Clash Detection)。

优势与局限：尺寸绝对精确，支持实体加工；但数据结构庞大嵌套深、拓扑一致性校验严苛，且显卡无法直接硬件光栅化（必须通过细分网格才能显示）。
范式三：多边形网格

原理：离散分面逼近与极简数组结构

Mesh 网格将任何复杂的形体表皮切分为大量的微小平面多边形（三角面 Triangle 或四边形 Quad）。

  • 彻底扁平化结构：
    • 顶点缓冲区 (Vertex Buffer)：连续存储三维浮点坐标数组 [(x0,y0,z0), (x1,y1,z1), ...]；
    • 面片索引表 (Face Index List)：记录每个面片引用的顶点序号 [(0, 1, 4), (1, 2, 4), ...]。
  • 抛弃拓扑开销：不保存复杂的半边或双向连通指针，内存紧凑线性排列，对 CPU Cache 和 GPU 显存极为友好。
  • 分段线性近似：本质是“用折面逼近光滑曲面”。网格越密越逼真，但数据量线性激增。

以参数化四棱锥为例

构建一个具有底面和尖顶的经典离散网格：

• 5 个顶点：底面 4 个角点 + 1 个空间锥尖顶点。
• 5 个面片：1 个四边形底面 + 4 个三角形侧面。
• 显卡读取方式：通过顶点缓冲区与面片索引直接批量送入显存。

Mesh 创建流程 · 步骤 1/3

填充连续顶点缓冲区 (Vertex Buffer)

网格表示的第一步是将所有独立几何特征点以扁平数组形式存入顶点缓冲区：

  • 无拓扑归属性：与 B-Rep 的顶点不同，Mesh 顶点没有任何“属于哪条边”的复杂指针，仅仅是内存中的一串紧凑浮点数。
  • 四棱锥的 5 个顶点：
    底面 4 点：MV0(0, 0, 0), MV1(w, 0, 0), MV2(w, d, 0), MV3(0, d, 0)；
    锥顶点：MV4(w/2, d/2, h) 位于中心高空。
  • 色彩规范：以海绿色（seagreen）圆球展示顶点缓冲中的数据点。
连续的顶点数组使得显卡 GPU 能够通过显存地址直接批量抓取顶点数据，吞吐速度极高。

Mesh 创建流程 · 步骤 2/3

组织面片拓扑索引表与三角剖分

第二步：建立面片索引表。Mesh 抛弃了单独的“边”结构，直接用整数索引元组来声明多边形面片：

  • 面片索引表结构：
    • 底面：(3, 2, 1, 0)（或剖分为两个三角形）；
    • 4 个侧三角面：(0, 1, 4), (1, 2, 4), (2, 3, 4), (3, 0, 4)。
  • 隐式连线：显卡读取索引表时，自动将索引对连接为三角形轮廓线框（如金黄色网格线所示）。
  • 轻量级优势：无需指针解引用，面片顶点复用率高，极大地压缩了内存占用。
面片索引表将独立的顶点组织成了具有几何外观的三角形外壳框架！

Mesh 创建流程 · 步骤 3/3

GPU 光栅化面片填充与平面着色 (Flat Shading)

第三步：GPU 硬件光栅化管线在三角形内部并行插值填充像素，并计算平面法向量进行着色：

  • 平面着色 (Flat Shading)： 每个多边形面片拥有唯一的平面法向量，光照下呈现清晰明暗分明的折面效果，生动展现多边形网格的“分面离散逼近”本质。
  • 色彩规范： 面片填充麦黄色（wheat），深色边框勾勒面片边界，节点保留海绿色。
  • 生成 PolyData： 调用 mesh.to_pyvista() 生成顶点+面片 PolyData，完全兼容 VTK 与 WebGL 渲染管线。
这就是我们最终在屏幕上见到的离散网格模型，它是现代计算机图形渲染的核心基石！

范式三：多边形网格

作用：GPU 硬件光栅化渲染、有限元分析与扫描重建

图形学与 GPU 渲染基石

DirectX、OpenGL、WebGL、Three.js、PyVista/VTK 等底层图形流水线只识别三角形网格。GPU 芯片架构拥有成千上万个光栅化核心，可微秒级并发处理数百万面片。

有限元受力分析 (FEM/FEA)

结构弹塑性、应力集中、大坝与深基坑开挖，必须将连续体划分为四面体 (Tet) 或六面体 (Hex) 网格单元，在节点上建立刚度矩阵并求解有限元偏微分方程。

点云重建与 3D 打印

激光雷达扫描三维点云通过泊松重建生成表面网格；无人机倾斜摄影实景三维自动三角化；3D 打印标准 STL 格式完全基于无拓扑的离散三角面片。

优势与局限：显卡渲染极速、通用跨平台；但只是分段线性近似有弦差，且缺乏拓扑约束，做布尔运算极其容易产生退化面 (Degenerate Faces)、自交缝隙和漏光漏风。

实战场景

同屏三几何体对比渲染实战

在脚本 examples/07_render_surface_brep_mesh_scene.py 中，我们将三大几何体置于同一 3D 视口中并排展示：

  • 空间平移错位：通过设置空间 X 轴位移 Offset，避免模型原点相互遮挡冲突。
  • 要素标记对比：同时展现 Surface 的等值线、B-Rep 的珊瑚红顶点与淡蓝面、Mesh 的海绿节点与麦黄三角面。
  • 一键调度：单次 RenderEngine.render([surf, brep, mesh]) 即可统一完成三维交互。
# 同屏对比渲染场景脚本核心逻辑 (07_render_...)
from brep_primitives import *
import pyvista as pv

# 1. 创建参数化马鞍曲面并平移至左侧 (X = -2500)
surf = HyperbolicParaboloid(a=1500, b=1500)
surf_grid = surf.to_pyvista().translate([-2500, 0, 0])

# 2. 创建精确实体长方体并置于中央 (X = 0)
brep = create_box_brep(width=400, depth=300, height=500)
brep_poly = brep.to_pyvista()

# 3. 创建参数化四棱锥网格并平移至右侧 (X = +2500)
mesh = create_pyramid_mesh(width=500, depth=500, height=600)
mesh_poly = mesh.to_pyvista().translate([2500, 0, 0])

# 4. 同一视口分层着色绘制
plotter = pv.Plotter()
plotter.add_mesh(surf_grid, color="lightseagreen", show_edges=True)
plotter.add_mesh(brep_poly, color="lightblue", opacity=0.85)
plotter.add_mesh(mesh_poly, color="wheat", show_edges=True)
plotter.show()
