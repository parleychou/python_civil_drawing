Lesson 1 · 包围盒数学与 SAT 定理

AABB vs OBB 空间紧致度与 15 轴分离判定

常规 AABB 沿坐标轴对齐，在倾斜斜撑构件中会产生剧烈的“包围盒体积空隙膨胀”导致误报虚警；而 OBB 沿主惯性轴紧致包络，结合 SAT 15 候选分离轴实现精准初筛。

旋转角度: 45° | AABB体积膨胀率: 7.7x
AABB: 6个正交区间判定 OBB: SAT 15轴投影测试
from collision import AABB, OBB # AABB 快速区间排查 aabb_a = AABB.from_mesh(brace_mesh) aabb_overlap = aabb_a.overlaps(aabb_b, tolerance=0.0) # OBB 15轴分离轴定理 (SAT) 精准判定 obb_a = OBB(center, axes, half_extents) is_real_clash = obb_a.overlaps(obb_b)
  • AABB 优势与局限：计算速度快 $O(1)$，但在大跨斜拉索、斜柱中体积严重虚胖；
  • OBB 紧致贴合：沿构件主轴建立正交基底，体积最小化，消除 90% 虚假包围盒相交；
  • SAT 15 轴完备性：3 条 A 面法向 + 3 条 B 面法向 + 9 条边矢量叉乘，投影重叠即碰撞。
Lesson 2 · 大规模场景初筛

空间网格哈希 (Spatial Hash Grid) O(N) 极速初筛

暴力两两排查复杂度高达 $O(N^2)$，面对超万构件即刻崩溃。通过三维体素空间哈希映射，将物体注册至覆盖体素桶，只比对同桶邻近构件，实现百倍加速。

体素网格: 5000mm | 1200构件加速比: 30.9x
空间体素划分 多单元格跨越注册 候选对哈希去重
grid = SpatialHashGrid(cell_size=5000.0) for item_id, aabb in scene_objects: grid.insert(item_id, aabb) # O(N) 极速提取相交候选对 candidates = grid.query_candidates(tolerance=100.0)
  • 坐标整除量化：$(i, j, k) = \lfloor (x, y, z) / \text{cell\_size} \rfloor$，常数时间索引；
  • 跨体素无缝包络：大构件跨越多格时全部注册，确保交界处构件绝不漏检；
  • 唯一配对收集器：通过规范化元组 (min(a,b), max(a,b)) 彻底避免重复检测。
Lesson 3 · 层次空间索引

层次包围盒树 (BVH) 构建与树-树递归剪枝

基于最长轴中位数自适应切分构建平衡 AABB 二叉树。遍历求交时两节点包围盒不相交则整棵子树直接剪枝，复杂度逼近 $O(N \log N)$，并支持高速射线拾取。

BVH 二叉深度: 3 层 | 射线拾取命中: 2 处
最长轴中位数划分 树-树递归求交 Slab 射线拾取
tree_a = BVHTree.build_top_down(beams) tree_b = BVHTree.build_top_down(pipes) # 双树递归剪枝，自动展开体积较大节点 clash_pairs = tree_a.intersect_tree(tree_b) # 模拟激光扫描/放样视线射线求交 hits = tree_a.ray_cast(origin, direction)
  • 自适应中位数分割：避免空间八叉树受空旷区域导致的深度不均衡，二叉树极致紧致；
  • 启发式优先级展开：递归遍历时优先展开体积更大的一方，极速命中分离面实施剪枝；
  • Slab 射线求交加速：三对平行平面求交区间交集快速判定，为全自动测距提供底层支撑。
Lesson 4 · 精确窄阶段与安全净距

硬碰撞穿透体积与软碰撞最小空间净距

突破传统包围盒初筛，深入三角面片级精细求交：精确解算穿透体积与侵入深度；对物理分离构件解算空间公垂线最近净距，排查运维检修缓冲区侵入。

结构梁 vs 暖通风管: 硬穿透 350mm | 水管软碰撞: 净距 45mm
Hard: 实体空间穿透 Soft: 净距小于安全阈值 公垂线欧氏距离
# 窄阶段精检与软硬碰撞一体化解算 rec = check_narrow_phase_clash( id_a="BEAM", mesh_a=beam, id_b="PIPE", mesh_b=pipe, clearance=100.0 # 规范安全间距 ) if rec.clash_type == ClashType.HARD: print(f"穿透深度: {rec.penetration_depth}mm")
  • 硬碰撞 (Hard Clash)：构件几何实体发生空间体积干涉，必须出具结构开洞或路由变更；
  • 软碰撞 (Soft Clash)：物理未接触，但侵入保温层、绝缘距离或施工吊装检修作业空间；
  • 面向对象原生内置：mesh_a.clash_with(mesh_b, clearance=100.0) 一行调用。
