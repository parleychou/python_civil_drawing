环境变量 PATH

PATH 的作用：让系统找到 Python

当你在终端输入 `python`，系统会在 PATH 记录的目录里寻找可执行程序。如果 PATH 没配置好，就会出现“不是内部或外部命令”。

环境变量不是 Python 语法问题，而是操作系统能否找到工具的问题。

常见现象

  • `python` 没反应或进入 Microsoft Store
  • `pip` 不能识别
  • PyCharm 和终端显示的 Python 版本不一致
  • 安装库成功，但运行代码仍提示找不到库
虚拟环境

每个课程项目，应该有自己的环境

虚拟环境可以把本课程需要的库和其他项目隔离开。这样安装 `pyvista`、`build123d`、`ezdxf` 等库时，不会影响系统 Python 或其他课程项目。

venv 命令

用 Python 自带工具创建虚拟环境

`venv` 是 Python 自带的虚拟环境工具，适合作为初学阶段的默认方案。后续如果涉及复杂科学计算环境，也可以再引入 Conda。

# 在项目根目录执行
python -m venv .venv

# Windows PowerShell 激活
.\.venv\Scripts\Activate.ps1

# Windows CMD 激活
.\.venv\Scripts\activate.bat

# macOS / Linux 激活
source .venv/bin/activate
PyCharm 配置

让 IDE 使用正确的解释器

PyCharm 能写代码，也能管理解释器。关键是确认项目解释器指向当前项目的 `.venv`，否则库可能装到别的 Python 里。

配置路径

  1. 打开 `File` → `Settings`。
  2. 进入 `Project` → `Python Interpreter`。
  3. 选择当前项目的 `.venv` 解释器。
  4. 通过 `+` 搜索并安装需要的库。
  5. 运行 `hello.py` 验证配置。
VS Code 配置
